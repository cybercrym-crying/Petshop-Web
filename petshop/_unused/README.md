# _unused

File di sini **tidak dipakai** oleh aplikasi (tidak ada view/URL/template yang
merujuknya) dan dipindahkan dari lokasi aslinya, dengan struktur folder yang sama,
supaya struktur proyek bersih tanpa menghapus apa pun.

Isinya: template registrasi & dashboard customer lama (tidak punya view), Home lama
(`index.html`), `catalog.html`/`shop.html` (digantikan `home_shop.html`), serta CSS/JS
versi desain lama yang tidak pernah dimuat.

Folder ini aman dihapus. Kalau ada yang ingin dipakai lagi, kembalikan ke app asalnya
(`<app>/templates/<app>/` untuk template, `<app>/static/<app>/` untuk CSS/JS/gambar).
